# 日本語

## Akyn Now Playing Dockについて

Akyn Now Playing Dockは、YouTubeで再生中の曲名などを取得し、OBS上へ表示するためのWindows向けツールです。

このリポジトリでは、以下を受け付けています。

- 不具合報告
- 改善提案
- 導入や更新に関する問題
- OBS連動に関する問題
- 曲名表示やYouTube取得に関する問題

## 不具合を報告する

以下のページから`不具合報告`を選択してください。

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

報告時には、可能な範囲で以下の情報を添付してください。

- 使用しているバージョン
- 発生した問題
- 再現手順
- 本来期待していた動作
- スクリーンショット
- 診断TXT
- 報告用ログTXT

## 改善を提案する

新機能や使いやすさに関する提案は、以下のページから`改善提案`を選択してください。

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

実装方法が分からなくても問題ありません。欲しい機能や困っている点を記入してください。

## 個人情報について

スクリーンショット、診断TXT、報告用ログTXTを投稿する前に、以下の情報が含まれていないか確認してください。

- 本名
- メールアドレス
- アカウント情報
- APIキー
- パスワード
- 個人用フォルダのパス
- その他、第三者に公開したくない情報

個人情報が含まれている場合は、該当部分を削除または隠してから投稿してください。

# English

## About Akyn Now Playing Dock

Akyn Now Playing Dock is a Windows tool that retrieves information about the currently playing YouTube track and displays it in OBS.

This repository accepts:

- Bug reports
- Feature requests
- Installation and update problems
- OBS integration problems
- Track display and YouTube capture problems

## Report a bug

Open the following page and select`Bug report (English)`.

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

Please include as much of the following information as possible:

- App version
- Description of the problem
- Steps to reproduce
- Expected behavior
- Screenshots
- Diagnostic TXT
- Support log TXT

## Suggest an improvement

For new features or usability improvements, open the following page and select`Feature request (English)`.

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

You do not need to know how to implement the feature. Describe the problem you are experiencing and what improvement you would like.

## Personal information

Before uploading screenshots, diagnostic TXT files, or support log TXT files, make sure they do not contain:

- Your real name
- Email addresses
- Account information
- API keys
- Passwords
- Personal folder paths
- Any other information you do not want to make public

Remove or hide any personal information before submitting an Issue.

# Português do Brasil

## Sobre o Akyn Now Playing Dock

O Akyn Now Playing Dock é uma ferramenta para Windows que obtém informações da música reproduzida no YouTube e as exibe no OBS.

Este repositório aceita:

- Relatórios de erros
- Sugestões de melhorias
- Problemas de instalação e atualização
- Problemas de integração com o OBS
- Problemas na exibição da música ou captura do YouTube

## Relatar um erro

Abra a página abaixo e selecione`Relatório de erro (Português do Brasil)`.

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

Inclua o máximo possível das seguintes informações:

- Versão do aplicativo
- Descrição do problema
- Passos para reproduzir
- Comportamento esperado
- Capturas de tela
- TXT de diagnóstico
- TXT de logs para suporte

## Sugerir uma melhoria

Para sugerir novas funções ou melhorias de usabilidade, abra a página abaixo e selecione`Sugestão de melhoria (Português do Brasil)`.

https://github.com/akyn171/AkynNowPlayingDock-Support/issues/new/choose

Não é necessário saber como implementar a função. Descreva o problema atual e a melhoria desejada.

## Informações pessoais

Antes de enviar capturas de tela, arquivos TXT de diagnóstico ou arquivos TXT de logs, confirme que eles não contêm:

- Nome completo
- Endereço de e-mail
- Informações da conta
- Chaves de API
- Senhas
- Caminhos de pastas pessoais
- Outras informações que você não deseja tornar públicas

Remova ou oculte qualquer informação pessoal antes de enviar o Issue.
